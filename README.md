# Asya Duru 4 yaşında

Asya Duru'nun 4. yaş günü partisi (31 Ekim 2026) için QR kodla açılan anı sayfası.
Misafirler telefonlarından Prenses Asya'ya bir "mektup" yazar: dilek, anı, fotoğraf ve sesli not.
Mektuplar özel bir Supabase veritabanında saklanır; bu repoda misafir fotoğrafı veya kişisel veri bulunmaz.

- `index.html`: misafir sayfası (QR bu adrese gider)
- `album.html`: ailenin şifreli albümü, slayt gösterisi ve canlı TV duvarı
